# 2026-11-03 0.4.0 — SabiRuby 0.9.0 に上げる（依存のバージョンだけ）

計画は `docs/plans/release-0.4-plan.md`。SabiRuby の `docs/plans/release-0.9-plan.md` の R6（下流のバージョン上げ）にあたり、
著者の判断（2026-11-03）で進めた。着手時の先頭は main の `3525007`（0.3.0）。手順は 0.3.0（`2026-10-19-release-0.3.md`）と同じ。

## 1. 変えたもの

- `Cargo.toml` の 5 行: `[dependencies]` の `sabiruby "0.8"→"0.9"`・`sabiruby-compiler "0.5"→"0.6"`、
  `[dev-dependencies]` の `sabiruby "0.8"→"0.9"`（`macros`）・`sabiruby-compiler "0.5"→"0.6"`・`sabiruby-serde "0.4"→"0.5"`。
- 同じファイルのコメント 3 か所: `rust-version` の出どころ（「sabiruby 0.9 says 1.85」。0.9.0 の `rust-version` も 1.85 なので
  `rust-version = "1.95.0"` は動かない）、VM の下限の理由（0.9.0 は足すだけのリリースで rubevy はそのまま建つが、0.x の caret では
  minor が major なので `^0.8` だとアプリが 0.9 を名指ししたときに VM が 2 つになる。0.8.0 の壊す API と、0.7 で入って rubevy が今も使うものは括弧で残した）、
  compiler の対応（0.6 が 0.9.x の VM と組む）。
- `version`: `rubevy` 0.3.0 → 0.4.0、`rubevy-build` 0.3.0 → 0.4.0（0.3.0 と同じ理由: minor を揃える慣習）。
  `cargo update -p sabiruby -p sabiruby-compiler -p sabiruby-serde` で lock を上げた（`sabiruby v0.8.0 -> v0.9.0`、
  `sabiruby-compiler v0.5.0 -> v0.6.0`、`sabiruby-serde v0.4.0 -> v0.5.0`。`sabiruby-macros` は 0.1.1 のまま）。
- CHANGELOG を `## 0.4.0 — 2026-11-03` に切った。README の Install（`rubevy "0.4"`、VM 0.9、compiler 0.6、「The version is 0.4」）。
  `outlook.md`／`outlook.ja.md` の公開の表に 0.4.0 の行。

コードは 1 行も変えていない。
